## Overview
- **Q1 (Interactive Text Changer):** Updates a paragraph's text to `"Hello there!"` when `"Change Message"` is clicked.
- **Q2 (Smart Number Validator):** Validates user input and compares numbers against `10`. Accept decimal numbers as valid numbers, while empty/whitespace input and non-numeric text count as invalid.
- **Q3 (Dynamic Number Generator):** Generates an ordered list from `"The number is 1"` to `"The number is 5"` without duplicates on repeated clicks.

## How to Run
1. Open the respective question folder (`Q1`, `Q2`, or `Q3`).
2. Open `index.html` in a modern desktop web browser (or launch via VS Code Live Server).
3. Click the button to verify the output.
